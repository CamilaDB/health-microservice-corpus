Project Context:
- Language: TypeScript
- Framework: NestJS
- Testing Framework: Jest
- ORM: TypeORM
- Architecture: Layered REST microservice with dependency injection
- Domain: Healthcare digital microservice inspired by HL7 workflows
- Controllers do not contain business logic
- Business rules are implemented in services
- Repository access uses dependency injection
- Validation uses DTOs and class-validator
- Exceptions use NestJS HttpException hierarchy
- Test files use .spec.ts suffix
- ts-jest is configured
- Jest is configured globally
